# PulseLib 1.21.1 MultiLoader — последовательный backlog

Дата: 2026-10-13. Основа — [текущий tracker](1.21.1-multiloader-stabilization-tracker-2026-10-13.md), 37 открытых подтверждённых ID. Это будущие независимые изменения; они не реализованы в стабилизации.

## Правила выполнения

Каждый ID — отдельная reviewable задача/commit/PR с минимальным diff. Сначала regression, затем локальная правка, `./gradlew build --no-daemon` и указанные opt-in проверки. Не менять версию, publication или CI. Повторно открывать H14/H17/C1/L38 можно только с новым witness.

Сначала P1: H18; H16 → H15 → H13; H1/H2/H3; H9/H10/H11/H12; H5/H6/H4; M-A3/M-A4/M-W1. Между независимыми подсистемами порядок можно менять; зависимости внутри цепочек сохраняются. P2/P3 — после соответствующих базовых задач. Любая новая design ambiguity сначала возвращается автору.
