## API и графическая архитектура

[Whole-library acceptance 7.2f](evidence/stage-7.2f-api.json) охватывает **458 canonical / 564 current named types**, **373 / 463 accessible types**, шесть version-specific compiler configurations и **17 614 erasure checks**. Все generated current class contracts, включая private/synthetic members и bridges, совпали с release JAR. **130 exact reviewed contracts / 366 module rows** перечисляют конкретные native adaptations, inherited changes, additive flag changes и approved removal. Сопоставление не освобождает целые packages от проверки.

В [§§77–81 журнала](26.1.2-multiloader.md) разобраны реальные adapters, restored overloads и исчезнувшие dependency types. ResourceLocation/Identifier, пакеты RenderType/PlayerModel, generic RS, RenderState/SubmitNodeCollector/GuiGraphicsExtractor и retired BEWLR не имеют прежнего 1.21.1 binary contract. Единственное явно одобренное пользователем удаление типа — [PItemAnimatable](approved-api-changes.json). Необъяснённых public/protected пропусков в принятом compiler surface не осталось; неизменная Minecraft 1.21.1 ABI не заявляется.

Сохранён **один native PGl backend**. Legacy facades делегируют его registry/geometry/streams/executor, без второго GPU renderer. Persistently mapped storage/fences, instance/indirect draws, shared deformation upload, четыре OIT слоя, отдельные ordinary-alpha/OIT paths, extracted snapshots и deferred ownership остаются на основе 26.1. Native streams подготавливаются до RenderPass, binding происходит внутри pass. Common включается в loader builds без дублирования implementation owners.

[GPU proof 7.2b](evidence/stage-7.2b-gpu-api.json) сохраняет **148 прежних method bodies** и отдельно перечисляет **шесть изменений**, включая shared geometry arena, guards и pose reset. Это не утверждение полной неизменности renderer после 26.1. [Material proof 7.2c](evidence/stage-7.2c-material-api.json) фиксирует настоящие RenderPipeline/codec/metadata adapters и emissiveVariant fix. Последняя проверка 7.2f сохранила **144 GPU class copies** в gl/legacy/deformer-gpu относительно принятой reference; сами helpers/constants 7.2f не меняли прежние **99 method/constructor bodies** четырёх затронутых classes.

## Что показывают performance данные

[Четыре CSV §74](evidence/stage-7.1b.2b.5.json) содержат **60 summary rows / 4800 основных measured samples**. Offscreen — 24 configurations/client, 1920×1080 / 2560×1440 / 3840×2160, обе routes и 0/1/16/128 quads, 32 warmup + 80 samples. World — шесть configurations/client, 1920×1080, 64 warmup + 80 samples: Fancy 0/1 и Fabulous 0/1/16/128; это не полный mode × workload cross-product.

Зафиксированное offscreen устройство — **NVIDIA GeForce GTX 1660 Ti / NVIDIA 615.78.08 / OpenGL 3.3**. Fabric использовал packaged demo JAR, NeoForge — source profile. GPU timestamps настоящие, asynchronous result retirement; glFinish/CPU timing/readback не подменяют measured intervals. Offscreen frame исключает title GUI/presentation; world interval охватывает GameRenderer.render, а не весь Minecraft tick/update/presentation. Metadata/compositor spans охватывают actual draw calls, без CPU binding setup.

Ниже сохранены отдельные исходные наблюдения. Они не устанавливают рейтинг loaders, допустимый budget или относительную скорость offscreen/world. В частности, Fabulous выполняет vanilla framegraph даже при нуле Pulse quads, Fancy — нет; empty intervals различаются по составу работы.

Каждый p95 относится к своим 80 samples. Индивидуальных per-frame samples в checked-in CSV нет, поэтому pooled p95/variance/confidence intervals не восстанавливаются; p95 разных строк не усредняются.

Observed steady-state OIT texture allocations равны нулю, resource identities после warmup стабильны; buffer_data_calls в этих rows — **0.000 storage events/sample**. Это не нулевые mapped writes, CPU/JVM allocations или whole-process memory consumption. Отдельная калибровка дала **восемь реальных storage events/client** и ненулевые warmup texture allocations. **167 156 query names created = deleted**, включая warmup/calibration/empty controls; эти lifetime totals не являются числом measured samples. Два skip-composite controls завершились ожидаемыми Java 255 / Gradle 1 на исходном draw-count guard.

Peak native OIT target storage в этих rows — **506.250 MiB** при 3840×2160 и **126.563 MiB** в world 1920×1080. Metadata **63.281 / 15.820 MiB уже включена** в эти totals. Это только учтённые native OIT textures, не весь VRAM footprint; pooled targets могут оставаться после empty workload. Driver-global VRAM delta и zero storage events не доказывают process leak freedom или общий memory budget.

**Измерения относятся к прежним production hashes**, сохранённым в machine report. После их commit `6549600` изменены 32 production Java units, включая PGl owners/streams в 7.2b. Совпадение нынешних JAR с 7.2f не переносит прежние timings на текущий binary. Нет сопоставимого запуска frozen 26.1, заданного performance threshold и нового benchmark текущего release. Следовательно, **превосходство над 26.1, cross-loader speed ranking и performance acceptance текущего build не установлены**. Для закрытия отчётного checkpoint эти неподтверждённые выводы не подменяются успешным functional PASS.

## Остаток миграции

Ранее открытый **5.2b.4** не закрыт последующими scopes автоматически. [5.2b.4c.2a](evidence/stage-5.2b.4c.2a.json) использует empty held items; [5.2b.4c.2b.2](evidence/stage-5.2b.4c.2b.2.json) отдельно исключает arbitrary legacy mesh clips / first-person held-item-map combinations; [6.2d.2b](evidence/stage-6.2d.2b.json) исключает full animated/map/held presentation. Поздний PlayerMotion подтверждает matrices/callbacks, а не эту pixel-матрицу.

Следующий checkpoint **5.2b.4d** должен разобрать только оставшиеся legacy mesh-controller clips, форматы самих attachment meshes в этом legacy scope и first-person held-item/map pixel combinations. Существующие статические Gecko/glTF rig, world/armor/particles/weather, ROOT/Camera, motion и cleanup matrices повторно переносить не требуется. До такого acceptance этап 5 остаётся частично выполненным. Survival death UI, произвольные platform/driver combinations и полноценный network dimension transfer также не заявляются проверенными; это ограничения охвата, а не новые автоматически добавленные этапы.

## Воспроизведение отчёта

```bash
python3 docs/porting/tools/summarize_migration.py --check
python3 docs/porting/tools/test_migration_summary.py
```

Первая команда сверяет pinned evidence/CSV, accepted cases, source/JAR identity и точное воспроизведение JSON. Вторая проверяет отказ при NaN, duplicate/missing configurations, неверном draw count, steady texture allocation, query leak и отсутствующей calibration. Ни одна не запускает Minecraft и не меняет исходные ветки. Для новых целевых runtime runs используются прежние documented runners с disposable directories; их необходимость определяется конкретным изменением или пробелом.

Рабочий WIP и protected worlds/logs сохранены. Push, публикация и release в scope этого checkpoint не входят.
