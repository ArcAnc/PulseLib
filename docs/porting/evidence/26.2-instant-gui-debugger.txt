Source evidence, resolved Minecraft 26.2 sources:
VulkanRenderPipeline.compile:219-220 sets withoutDepthPipeline=0 when depth state is non-null;
isValid checks withDepthPipeline only. VulkanRenderPass.setPipeline:125 selects the without-depth
handle for a depthless pass. The zero handle is inferred from that source branch and observed
non-null depth state; it was not recorded by the native-library logpoint.
Correction: select a native RenderPipeline descriptor with no depth state for a target without
depth, preserving shader defines, bind groups, vertex format, blending, topology and cull state.
This uses the supported RHI API and applies to instant and ordinary renderers on both backends.
No world depth texture is substituted for a depthless local target.
