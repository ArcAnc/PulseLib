# API Reference

This page maps the Minecraft 26.1.2 MultiLoader API. Source links use the `common/`, `fabric/` and `neoforge/` layout of this branch. Classes marked internal in source are omitted unless they explain a public workflow.

## Animatables and controllers

* [`PAnimatable<T>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimatable.java) defines animatable objects.
* [`PAnimationManager<T>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationManager.java) owns regular and graph controller factories, live controllers, and the bound model.
* [`PAnimationController<T>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationController.java) plays a `PRawAnimation` or `PAnimationGraph`, exposes graph parameters, controls timing, and owns persistent Molang state.
* [`InstanceAnimationManager<T>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/animatable/instance/InstanceAnimationManager.java), [`SingletonAnimationManager<T>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/animatable/singleton/SingletonAnimationManager.java), and [`AnimManagerKey`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/animatable/AnimManagerKey.java) provide per-instance and keyed state.
* [`ControllerState`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/animatable/ControllerState.java) is `PLAY`, `PAUSE`, or `STOP`.

## Animation data and graphs

* [`PRawAnimation`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PRawAnimation.java) is a builder for staged playback sequences; [`PAnimationType`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationType.java) selects once, hold, or cycle behavior.
* [`PAnimationGraph`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationGraph.java), [`PAnimationState`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationState.java), [`PAnimationTransition`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationTransition.java), [`PCondition`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PCondition.java), and [`PAnimationGraphRuntime`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationGraphRuntime.java) implement graph states, blend spaces, overlays, transitions, and runtime state.
* [`PAnimationParameters`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationParameters.java) stores graph numeric/boolean inputs and one-use triggers. [`PInterruptionPolicy`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PInterruptionPolicy.java) is used by graph transitions; [`PTransitionInterruptionPolicy`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PTransitionInterruptionPolicy.java) is used by player-animation activation crossfades.
* [`PAnimation`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimation.java), [`PBoneAnimation`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PBoneAnimation.java), [`PAnimationTrack<T>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationTrack.java), and [`PKeyframe<T>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PKeyframe.java) represent parsed animation data.
* [`PAnimationChannelType<T>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationChannelType.java) is the generic channel contract. [`PAnimationChannel`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationChannel.java) supplies vector and quaternion implementations; PulseLib registers position, rotation, and scale channel types.
* [`PInterpolation`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PInterpolation.java) and [`PInterpolationType`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PInterpolationType.java) control keyframe interpolation. [`PBlendMode`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PBlendMode.java) and [`PPoseBlendMode`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PPoseBlendMode.java) control pose blending.
* [`PPose`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PPose.java), [`PModelPose`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PModelPose.java), and [`PAnimationPoseResolver`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationPoseResolver.java) evaluate local and model-space poses.
* [`PRootMotionRuntime`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PRootMotionRuntime.java) and [`PRootMotionDelta`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PRootMotionDelta.java) extract incremental root motion from an animation.
* [`PAnimationEvent`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationEvent.java), [`PAnimationEventType`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationEventType.java), and [`PAnimationEventDispatcher`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationEventDispatcher.java) provide typed sound, particle, camera-shake, locator-callback, and graph-parameter events.

## Models and loaders

* [`PModelData`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/renderer/modelData/PModelData.java) identifies canonical models through `block(...)`, `item(...)`, `entity(...)`, `entityLayer(...)`, and `direct(...)` factories.
* [`PModel`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/PModel.java), [`PBone`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/PBone.java), [`PMesh`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/PMesh.java), [`PMeshPrimitive`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/PMeshPrimitive.java), and [`PMaterial`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/PMaterial.java) are raw data. [`PBakedModel`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedModel.java), [`PBakedBone`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedBone.java), and [`PBakedMesh`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedMesh.java) are the baked runtime representation.
* [`PMeshRenderContext`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderContext.java) and [`PMeshRenderResolver`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderResolver.java) customize render type, colour, lighting, overlay, deformation, texture, emissive state, and alpha mode for each baked mesh. [`PMeshRenderMaterial`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderMaterial.java) resolves those material overrides.
* [`PModelCache`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/util/PModelCache.java) manages loaders, resource reloads, baking, and cache cleanup. [`PModelLoader`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/data/PModelLoader.java) is the extension point.
* glTF classes are in [`data.gltf`](https://github.com/ArcAnc/PulseLib/tree/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/data/gltf): [`PGltfModelLoader`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/data/gltf/PGltfModelLoader.java), [`PGltfModelParser`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/data/gltf/PGltfModelParser.java), and [`PGltfAnimationEventSidecarParser`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/data/gltf/PGltfAnimationEventSidecarParser.java).
* Gecko and Molang classes are in [`data.gecko`](https://github.com/ArcAnc/PulseLib/tree/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/data/gecko): [`PGeckoModelLoader`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoModelLoader.java), [`PGeckoModelParser`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoModelParser.java), [`PGeckoAnimationEventParser`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoAnimationEventParser.java), and [`MolangParser`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/data/gecko/MolangParser.java).

## Rendering, textures, and attachments

* [`PRenderer<T, RS>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/renderer/PRenderer.java), [`PBlockRenderer<T, RS>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/renderer/PBlockRenderer.java), [`PItemRenderer<T, RS>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/renderer/PItemRenderer.java), [`PEntityRenderer<T, RS>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/renderer/PEntityRenderer.java), and [`PEntityRenderLayer<T, RS>`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/renderer/PEntityRenderLayer.java) are renderer entry points.
* [`PRenderTypes`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/util/PRenderTypes.java) provides compatible triangle render types; [`PRenderQueue`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/renderer/PRenderQueue.java) batches their submissions.
* [`PModelResource`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/resource/PModelResource.java), [`PTextureReference`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/PTextureReference.java), [`PResourceCache`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/util/PResourceCache.java), [`RuntimeLoader`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/textures/atlas/RuntimeLoader.java), and [`PLibSpriteMetadata`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/textures/atlas/PLibSpriteMetadata.java) manage model resources, texture-reference normalization, the runtime texture atlas, and its emissive/alpha metadata. [`PAlphaMode`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/textures/PAlphaMode.java) and [`PTextureAlphaClassifier`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/model/textures/PTextureAlphaClassifier.java) select opaque, cutout, or translucent rendering.
* Attachments are centered on [`PLivingAttachmentDefinition`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/util/attachments/PLivingAttachmentDefinition.java), [`PLivingAttachments`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/util/attachments/PLivingAttachments.java), [`PAttachmentBinding`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/util/attachments/PAttachmentBinding.java), and [`PAttachmentAnchor`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/util/attachments/PAttachmentAnchor.java).

## Player animations

* [`PPlayerAnimationDefinition`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDefinition.java) configures bindings, masks, blend modes, weights, activation crossfades, cycle synchronization, controllers, Molang queries, animation-owned mesh deformers through `Builder.deform(...)`, and opt-in first-person pose integration through `Builder.firstPerson(...)`, `Builder.itemRenderPolicy(...)`, and `Builder.itemVisibility(...)`.
* [`PPlayerAnimations`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimations.java), [`PPlayerAnimationHandle`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationHandle.java), and [`PPlayerAnimationInstance`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationInstance.java) expose runtime registration and per-player state.
* [`PPlayerPart`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerPart.java), [`PPlayerAnimationMask`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationMask.java), [`PPlayerAnimationBlendMode`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationBlendMode.java), and [`PPlayerAnimationWeight`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationWeight.java) define how a player pose is applied.
* [`PPlayerAnimationAnchors`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationAnchors.java) provides the reserved first-person camera and physical-item anchors. [`PPlayerFirstPersonSettings`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PPlayerFirstPersonSettings.java) enables pose integration and selects animated or vanilla camera handling through [`PFirstPersonCameraMode`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PFirstPersonCameraMode.java). [`PFirstPersonRenderMode`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PFirstPersonRenderMode.java), [`PFirstPersonArmPose`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PFirstPersonArmPose.java), and [`PFirstPersonItemPose`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PFirstPersonItemPose.java) represent the resulting arm and item commands. The public `PPlayerAnimationDefinition.ItemRenderPolicy` and `ItemVisibilityPolicy` control first-person held-item visibility.
* [`PPlayerAnimatedAttachmentRenderer`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/attachment/PPlayerAnimatedAttachmentRenderer.java), registered in `IPulseClientPlugin.registerAnimatedAttachments(PAnimatedAttachmentRegistrar)`, renders custom content at a sampled [`PPlayerAnimationAnchor`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationAnchor.java) in third or first person.
* [`PPlayerAnimationDeformer`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformer.java), [`PPlayerAnimationDeformerValueSource`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformerValueSource.java), and [`PPlayerAnimationDeformerContext`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformerContext.java) attach a deformer stack to a definition and sample channels from its player/controller context.

## Mesh deformers

## Render plans and native boundaries

* [`PGeometryData`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/renderer/plan/PGeometryData.java), `PDynamicGeometry`, `PInstanceHeader`, `PFrameCompiler<S>`, `PRenderPlan`, `PRenderFrame`, and `PRenderExecutor` form the canonical submission/plan contract. See [Render types and queue](render-types-and-queue.md).
* [`PGlDynamicGeometry`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/renderer/gl/PGlDynamicGeometry.java), `PGlResourceRegistry`, and `PGlMultiDrawExecutor` provide the native backend. Canonical `legacy.Gl*` facades delegate to these resources and streams.
* [`PTransparencyMode`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/content/renderer/plan/PTransparencyMode.java) chooses ordinary alpha or supported OIT separately from the native material. `PRenderContexts` isolates GUI and offscreen execution from world queues.
* Minecraft uses `Identifier`, `rendertype.RenderType`, immutable `RenderPipeline`, and `GuiGraphicsExtractor`. Item renderers implement `SpecialModelRenderer`; renderer classes carry an explicit render-state generic in addition to the animatable type. `PItemAnimatable`, BEWLR and mutable `ShaderInstance` integrations are retired.
* `PLibHelper.renderModelInGui(...)` extracts an animated model into the native picture-in-picture GUI path. See [GUI rendering](gui-rendering.md).

## Events and helpers

* [Automatic plugins](plugins.md) expose scoped type, model, attachment and player-animation registrars through `@PulsePlugin`, `IPulseCommonPlugin` and `IPulseClientPlugin`.
* [`PLibHelper`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/util/helpers/PLibHelper.java), [`PLibCodecs`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/util/helpers/PLibCodecs.java), and [`PLibDatabase`](https://github.com/ArcAnc/PulseLib/blob/26.1.2-multiloader/common/src/main/java/com/arcanc/pulselib/util/PLibDatabase.java) are common integration helpers.
