# API Reference

This page maps the Minecraft 26.2 MultiLoader API. Source links use the `common/`, `fabric/` and `neoforge/` layout of this branch. Classes marked internal in source are omitted unless they explain a public workflow.

## Animatables and controllers

* [`PAnimatable<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimatable.java) defines animatable objects.
* [`PAnimationManager<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationManager.java) owns regular and graph controller factories, live controllers, and the bound model.
* [`PAnimationController<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationController.java) plays a `PRawAnimation` or `PAnimationGraph`, exposes graph parameters, controls timing, and owns persistent Molang state.
* [`InstanceAnimationManager<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/instance/InstanceAnimationManager.java), [`SingletonAnimationManager<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/singleton/SingletonAnimationManager.java), and [`AnimManagerKey`](../common/src/main/java/com/arcanc/pulselib/content/animatable/AnimManagerKey.java) provide per-instance and keyed state.
* [`ControllerState`](../common/src/main/java/com/arcanc/pulselib/content/animatable/ControllerState.java) is `PLAY`, `PAUSE`, or `STOP`.

## Animation data and graphs

* [`PRawAnimation`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PRawAnimation.java) is a builder for staged playback sequences; [`PAnimationType`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationType.java) selects once, hold, or cycle behavior.
* [`PAnimationGraph`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationGraph.java), [`PAnimationState`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationState.java), [`PAnimationTransition`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationTransition.java), [`PCondition`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PCondition.java), and [`PAnimationGraphRuntime`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationGraphRuntime.java) implement graph states, blend spaces, overlays, transitions, and runtime state.
* [`PAnimationParameters`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationParameters.java) stores graph numeric/boolean inputs and one-use triggers. [`PInterruptionPolicy`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PInterruptionPolicy.java) is used by graph transitions; [`PTransitionInterruptionPolicy`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PTransitionInterruptionPolicy.java) is used by player-animation activation crossfades.
* [`PAnimation`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimation.java), [`PBoneAnimation`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PBoneAnimation.java), [`PAnimationTrack<T>`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationTrack.java), and [`PKeyframe<T>`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PKeyframe.java) represent parsed animation data.
* [`PAnimationChannelType<T>`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationChannelType.java) is the generic channel contract. [`PAnimationChannel`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationChannel.java) supplies vector and quaternion implementations; PulseLib registers position, rotation, and scale channel types.
* [`PInterpolation`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PInterpolation.java) and [`PInterpolationType`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PInterpolationType.java) control keyframe interpolation. [`PBlendMode`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PBlendMode.java) and [`PPoseBlendMode`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PPoseBlendMode.java) control pose blending.
* [`PPose`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PPose.java), [`PModelPose`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PModelPose.java), and [`PAnimationPoseResolver`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationPoseResolver.java) evaluate local and model-space poses.
* [`PRootMotionRuntime`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PRootMotionRuntime.java) and [`PRootMotionDelta`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PRootMotionDelta.java) extract incremental root motion from an animation.
* [`PAnimationEvent`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationEvent.java), [`PAnimationEventType`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationEventType.java), and [`PAnimationEventDispatcher`](../common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationEventDispatcher.java) provide typed sound, particle, camera-shake, locator-callback, and graph-parameter events.

## Models and loaders

* [`PModelData`](../common/src/main/java/com/arcanc/pulselib/content/renderer/modelData/PModelData.java) identifies canonical models through `block(...)`, `item(...)`, `entity(...)`, `entityLayer(...)`, and `direct(...)` factories.
* [`PModel`](../common/src/main/java/com/arcanc/pulselib/content/model/PModel.java), [`PBone`](../common/src/main/java/com/arcanc/pulselib/content/model/PBone.java), [`PMesh`](../common/src/main/java/com/arcanc/pulselib/content/model/PMesh.java), [`PMeshPrimitive`](../common/src/main/java/com/arcanc/pulselib/content/model/PMeshPrimitive.java), and [`PMaterial`](../common/src/main/java/com/arcanc/pulselib/content/model/PMaterial.java) are raw data. [`PBakedModel`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedModel.java), [`PBakedBone`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedBone.java), and [`PBakedMesh`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedMesh.java) are the baked runtime representation.
* [`PMeshRenderContext`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderContext.java) and [`PMeshRenderResolver`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderResolver.java) customize render type, colour, lighting, overlay, deformation, texture, emissive state, and alpha mode for each baked mesh. [`PMeshRenderMaterial`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderMaterial.java) resolves those material overrides.
* [`PModelCache`](../common/src/main/java/com/arcanc/pulselib/util/PModelCache.java) manages loaders, resource reloads, baking, and cache cleanup. [`PModelLoader`](../common/src/main/java/com/arcanc/pulselib/data/PModelLoader.java) is the extension point.
* glTF classes are in [`data.gltf`](../common/src/main/java/com/arcanc/pulselib/data/gltf): [`PGltfModelLoader`](../common/src/main/java/com/arcanc/pulselib/data/gltf/PGltfModelLoader.java), [`PGltfModelParser`](../common/src/main/java/com/arcanc/pulselib/data/gltf/PGltfModelParser.java), and [`PGltfAnimationEventSidecarParser`](../common/src/main/java/com/arcanc/pulselib/data/gltf/PGltfAnimationEventSidecarParser.java).
* Gecko and Molang classes are in [`data.gecko`](../common/src/main/java/com/arcanc/pulselib/data/gecko): [`PGeckoModelLoader`](../common/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoModelLoader.java), [`PGeckoModelParser`](../common/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoModelParser.java), [`PGeckoAnimationEventParser`](../common/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoAnimationEventParser.java), and [`MolangParser`](../common/src/main/java/com/arcanc/pulselib/data/gecko/MolangParser.java).

## Rendering, textures, and attachments

* [`PRenderer<T, RS>`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PRenderer.java), [`PBlockRenderer<T, RS>`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PBlockRenderer.java), [`PItemRenderer<T, RS>`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PItemRenderer.java), [`PEntityRenderer<T, RS>`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PEntityRenderer.java), and [`PEntityRenderLayer<T, RS>`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PEntityRenderLayer.java) are renderer entry points.
* [`PRenderTypes`](../common/src/main/java/com/arcanc/pulselib/util/PRenderTypes.java) provides compatible triangle render types; [`PRenderQueue`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PRenderQueue.java) batches their submissions.
* [`PModelResource`](../common/src/main/java/com/arcanc/pulselib/content/model/resource/PModelResource.java), [`PTextureReference`](../common/src/main/java/com/arcanc/pulselib/content/model/PTextureReference.java), [`PResourceCache`](../common/src/main/java/com/arcanc/pulselib/util/PResourceCache.java), [`RuntimeLoader`](../common/src/main/java/com/arcanc/pulselib/content/model/textures/atlas/RuntimeLoader.java), and [`PLibSpriteMetadata`](../common/src/main/java/com/arcanc/pulselib/content/model/textures/atlas/PLibSpriteMetadata.java) manage model resources, texture-reference normalization, the runtime texture atlas, and its emissive/alpha metadata. [`PAlphaMode`](../common/src/main/java/com/arcanc/pulselib/content/model/textures/PAlphaMode.java) and [`PTextureAlphaClassifier`](../common/src/main/java/com/arcanc/pulselib/content/model/textures/PTextureAlphaClassifier.java) select opaque, cutout, or translucent rendering.
* Attachments are centered on [`PLivingAttachmentDefinition`](../common/src/main/java/com/arcanc/pulselib/util/attachments/PLivingAttachmentDefinition.java), [`PLivingAttachments`](../common/src/main/java/com/arcanc/pulselib/util/attachments/PLivingAttachments.java), [`PAttachmentBinding`](../common/src/main/java/com/arcanc/pulselib/util/attachments/PAttachmentBinding.java), and [`PAttachmentAnchor`](../common/src/main/java/com/arcanc/pulselib/util/attachments/PAttachmentAnchor.java).

## Player animations

* [`PPlayerAnimationDefinition`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDefinition.java) configures bindings, masks, blend modes, weights, activation crossfades, cycle synchronization, controllers, Molang queries, animation-owned mesh deformers through `Builder.deform(...)`, and opt-in first-person pose integration through `Builder.firstPerson(...)`, `Builder.itemRenderPolicy(...)`, and `Builder.itemVisibility(...)`.
* [`PPlayerAnimations`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimations.java), [`PPlayerAnimationHandle`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationHandle.java), and [`PPlayerAnimationInstance`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationInstance.java) expose runtime registration and per-player state.
* [`PPlayerPart`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerPart.java), [`PPlayerAnimationMask`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationMask.java), [`PPlayerAnimationBlendMode`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationBlendMode.java), and [`PPlayerAnimationWeight`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationWeight.java) define how a player pose is applied.
* [`PPlayerAnimationAnchors`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationAnchors.java) provides the reserved first-person camera and physical-item anchors. [`PPlayerFirstPersonSettings`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PPlayerFirstPersonSettings.java) enables pose integration and selects animated or vanilla camera handling through [`PFirstPersonCameraMode`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PFirstPersonCameraMode.java). [`PFirstPersonRenderMode`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PFirstPersonRenderMode.java), [`PFirstPersonArmPose`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PFirstPersonArmPose.java), and [`PFirstPersonItemPose`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PFirstPersonItemPose.java) represent the resulting arm and item commands. The public `PPlayerAnimationDefinition.ItemRenderPolicy` and `ItemVisibilityPolicy` control first-person held-item visibility.
* [`PPlayerAnimatedAttachmentRenderer`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/attachment/PPlayerAnimatedAttachmentRenderer.java), registered in `IPulseClientPlugin.registerAnimatedAttachments(PAnimatedAttachmentRegistrar)`, renders custom content at a sampled [`PPlayerAnimationAnchor`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationAnchor.java) in third or first person.
* [`PPlayerAnimationDeformer`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformer.java), [`PPlayerAnimationDeformerValueSource`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformerValueSource.java), and [`PPlayerAnimationDeformerContext`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformerContext.java) attach a deformer stack to a definition and sample channels from its player/controller context.

## Mesh deformers

* [`PMeshDeformer`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PMeshDeformer.java), [`PDeformerInstance`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PDeformerInstance.java), [`PDeformerStack`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PDeformerStack.java), and [`PChannelReference`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PChannelReference.java) define and evaluate reusable deformations.
* Built-in operations are [`PBendDeformer`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PBendDeformer.java), [`PHingeDeformer`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PHingeDeformer.java), [`PTwistDeformer`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PTwistDeformer.java), [`PStretchDeformer`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PStretchDeformer.java), [`PSquashDeformer`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PSquashDeformer.java), [`PTaperDeformer`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PTaperDeformer.java), and [`PWaveDeformer`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PWaveDeformer.java).
* [`PMeshDeformation`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/PMeshDeformation.java), [`PGpuDeformedMeshBuffers`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PGpuDeformedMeshBuffers.java), and [`PGpuDeformerBuffers`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/gpu/PGpuDeformerBuffers.java) drive supported shader-side deformation and optional subdivision. Custom prepared operations use CPU dynamic geometry through `PDeformedMeshBuffers`. [`PPlayerMeshDeformers`](../common/src/main/java/com/arcanc/pulselib/content/player/deformer/PPlayerMeshDeformers.java) is the independent player-binding API.

## Render plans and native boundaries

* [`PGeometryData`](../common/src/main/java/com/arcanc/pulselib/content/renderer/plan/PGeometryData.java), `PDynamicGeometry`, `PInstanceHeader`, `PFrameCompiler<S>`, `PRenderPlan`, `PRenderFrame`, and `PRenderExecutor` form the canonical submission/plan contract. See [Render types and queue](render-types-and-queue.md).
* [`PGeometrySource`](../common/src/main/java/com/arcanc/pulselib/content/renderer/plan/PGeometrySource.java) describes portable dynamic CPU geometry. The canonical [`PGlDynamicGeometry`](../common/src/main/java/com/arcanc/pulselib/content/renderer/gl/PGlDynamicGeometry.java) implements it and works with the native queue. The built-in RHI executors are internal.
* [`PTransparencyMode`](../common/src/main/java/com/arcanc/pulselib/content/renderer/plan/PTransparencyMode.java) chooses ordinary alpha or supported OIT separately from the native material. `PRenderContexts` isolates GUI and offscreen execution from world queues.
* Minecraft uses `Identifier`, `rendertype.RenderType`, immutable `RenderPipeline`, and `GuiGraphicsExtractor`. Item renderers implement `SpecialModelRenderer`; renderer classes carry an explicit render-state generic in addition to the animatable type. `PItemAnimatable`, BEWLR and mutable `ShaderInstance` integrations are retired.
* `PLibHelper.renderModelInGui(...)` extracts an animated model into the native picture-in-picture GUI path. See [GUI rendering](gui-rendering.md).
* The [`AtlasBufferBuilder`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/AtlasBufferBuilder.java) constructor takes `PrimitiveTopology`. The [`PClientRenderHooks`](../common/src/main/java/com/arcanc/pulselib/platform/PClientRenderHooks.java) stencil bridge uses `GpuFormat` in `install(Predicate<GpuFormat>, ArmRenderer)` and `hasStencilAspect(GpuFormat)`.

## Events and helpers

* [Automatic plugins](plugins.md) expose scoped type, model, attachment and player-animation registrars through `@PulsePlugin`, `IPulseCommonPlugin` and `IPulseClientPlugin`.
* [`PLibHelper`](../common/src/main/java/com/arcanc/pulselib/util/helpers/PLibHelper.java), [`PLibCodecs`](../common/src/main/java/com/arcanc/pulselib/util/helpers/PLibCodecs.java), and [`PLibDatabase`](../common/src/main/java/com/arcanc/pulselib/util/PLibDatabase.java) are common integration helpers.
