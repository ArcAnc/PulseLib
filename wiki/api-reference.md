# API Reference

This page is a compact map of the current PulseLib public API. Classes marked internal in source are omitted unless they explain a public workflow.

Source links resolve against this checkout's Common/Fabric/NeoForge layout. For full signatures and contracts, generate each module's Javadoc with the [documentation tasks](installation.md#building-pulselib).

## Animatables and controllers

* [`PAnimatable<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimatable.java) and [`PItemAnimatable<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/PItemAnimatable.java) define animatable objects.
* [`PAnimationManager<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationManager.java) owns regular and graph controller factories, live controllers, and the bound model.
* [`PAnimationController<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationController.java) plays a `PRawAnimation` or `PAnimationGraph`, exposes graph parameters, controls timing, and owns persistent Molang state.
* [`InstanceAnimationManager<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/instance/InstanceAnimationManager.java), [`SingletonAnimationManager<T>`](../common/src/main/java/com/arcanc/pulselib/content/animatable/singleton/SingletonAnimationManager.java), and [`AnimManagerKey`](../common/src/main/java/com/arcanc/pulselib/content/animatable/AnimManagerKey.java) provide per-instance and keyed state.
* [`ControllerState`](../common/src/main/java/com/arcanc/pulselib/content/animatable/ControllerState.java) is `PLAY`, `PAUSE`, or `STOP`.

## Animation data and graphs

* [`PRawAnimation`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PRawAnimation.java) is a builder for staged playback sequences; [`PAnimationType`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationType.java) selects once, hold, or cycle behavior.
* [`PAnimationGraph`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationGraph.java), [`PAnimationState`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationState.java), [`PAnimationTransition`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationTransition.java), [`PCondition`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PCondition.java), and [`PAnimationGraphRuntime`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationGraphRuntime.java) implement graph states, blend spaces, overlays, transitions, and runtime state.
* [`PAnimationParameters`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationParameters.java) stores graph numeric/boolean inputs and one-use triggers. [`PInterruptionPolicy`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PInterruptionPolicy.java) is used by graph transitions; [`PTransitionInterruptionPolicy`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PTransitionInterruptionPolicy.java) is used by player-animation activation crossfades.
* [`PAnimation`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimation.java), [`PBoneAnimation`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PBoneAnimation.java), [`PAnimationTrack<T>`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationTrack.java), and [`PKeyframe<T>`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PKeyframe.java) represent parsed animation data.
* [`PAnimationChannelType<T>`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationChannelType.java) is the generic channel contract. [`PAnimationChannel`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationChannel.java) supplies vector and quaternion implementations; PulseLib registers position, rotation, and scale channel types.
* [`PInterpolation`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PInterpolation.java) and [`PInterpolationType`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PInterpolationType.java) control keyframe interpolation. [`PBlendMode`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PBlendMode.java) and [`PPoseBlendMode`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PPoseBlendMode.java) control pose blending.
* [`PPose`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PPose.java), [`PModelPose`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PModelPose.java), and [`PAnimationPoseResolver`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationPoseResolver.java) evaluate local and model-space poses.
* [`PRootMotionRuntime`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PRootMotionRuntime.java) and [`PRootMotionDelta`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PRootMotionDelta.java) extract incremental animation-space displacement data. Extraction does not change entity position, deltaMovement, hitboxes, collisions, or server state. PulseLib's ROOT rendering is visual only; applying the data to gameplay movement is the consuming mod's responsibility. See [Visual Root Motion](player-animations.md#visual-root-motion).
* [`PAnimationEvent`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationEvent.java), [`PAnimationEventType`](../common/src/main/java/com/arcanc/pulselib/content/model/animation/PAnimationEventType.java), and [`PAnimationEventDispatcher`](../common/src/main/java/com/arcanc/pulselib/content/animatable/PAnimationEventDispatcher.java) provide typed sound, particle, camera-shake, callback, and parameter events. See [Animation events](animation-events.md) for side policies and delivery intervals.

## Models and loaders

* [`PModelData`](../common/src/main/java/com/arcanc/pulselib/content/renderer/modelData/PModelData.java) identifies canonical models through `block`, `item`, `entity`, `entityLayer`, and `direct` factories. `PModelResource` owns material texture references.
* [`PModel`](../common/src/main/java/com/arcanc/pulselib/content/model/PModel.java), [`PBone`](../common/src/main/java/com/arcanc/pulselib/content/model/PBone.java), and [`PMesh`](../common/src/main/java/com/arcanc/pulselib/content/model/PMesh.java) are raw data. [`PBakedModel`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedModel.java), [`PBakedBone`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedBone.java), and [`PBakedMesh`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PBakedMesh.java) are the baked runtime representation.
* [`PMeshRenderContext`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderContext.java) carries mesh material and deformation overrides for queued and immediate rendering. [`PMeshRenderResolver`](../common/src/main/java/com/arcanc/pulselib/content/model/baked/PMeshRenderResolver.java) supplies per-mesh resolution for direct model drawing; built-in renderers also expose bone/mesh resolver hooks.
* [`PModelCache`](../common/src/main/java/com/arcanc/pulselib/util/PModelCache.java) manages loaders, resource reloads, baking, and cache cleanup. [`PModelLoader`](../common/src/main/java/com/arcanc/pulselib/data/PModelLoader.java) resolves canonical IDs, and [`PLoadedModel`](../common/src/main/java/com/arcanc/pulselib/data/PLoadedModel.java) carries the selected physical source through loader-specific processing.
* glTF classes are in [`data.gltf`](../common/src/main/java/com/arcanc/pulselib/data/gltf): [`PGltfModelLoader`](../common/src/main/java/com/arcanc/pulselib/data/gltf/PGltfModelLoader.java), [`PGltfModelParser`](../common/src/main/java/com/arcanc/pulselib/data/gltf/PGltfModelParser.java), and [`PGltfAnimationEventSidecarParser`](../common/src/main/java/com/arcanc/pulselib/data/gltf/PGltfAnimationEventSidecarParser.java).
* Gecko and Molang classes are in [`data.gecko`](../common/src/main/java/com/arcanc/pulselib/data/gecko): [`PGeckoModelLoader`](../common/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoModelLoader.java), [`PGeckoModelParser`](../common/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoModelParser.java), [`PGeckoAnimationEventParser`](../common/src/main/java/com/arcanc/pulselib/data/gecko/PGeckoAnimationEventParser.java), and [`MolangParser`](../common/src/main/java/com/arcanc/pulselib/data/gecko/MolangParser.java).
* [`PAnimationSidecarParser`](../common/src/main/java/com/arcanc/pulselib/data/PAnimationSidecarParser.java) handles the shared event and visibility sidecar format used by the built-in loaders.

## Rendering, textures, and attachments

* [`PRenderer<T>`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PRenderer.java), [`PBlockRenderer<T>`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PBlockRenderer.java), [`PItemRenderer<T>`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PItemRenderer.java), [`PEntityRenderer<T>`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PEntityRenderer.java), and [`PEntityRenderLayer<T>`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PEntityRenderLayer.java) are renderer entry points.
* [`PRenderTypes`](../common/src/main/java/com/arcanc/pulselib/util/PRenderTypes.java) provides compatible triangle render types; [`PRenderQueue`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PRenderQueue.java) batches their submissions.
* [`PRenderContexts`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PRenderContexts.java) isolates GUI/offscreen entity submissions and identifies world/first-person passes. [`PRenderStagesHandler`](../common/src/main/java/com/arcanc/pulselib/content/renderer/PRenderStagesHandler.java) owns normal world flush and OIT timing on both loaders.
* [`PGeometryData`](../common/src/main/java/com/arcanc/pulselib/content/renderer/plan/PGeometryData.java) is immutable static triangle data, and [`PInstanceHeader`](../common/src/main/java/com/arcanc/pulselib/content/renderer/plan/PInstanceHeader.java) carries a transform, color, lighting, overlay, and optional GPU-deformer offsets for one queued instance. [`PDrawCommand`](../common/src/main/java/com/arcanc/pulselib/content/renderer/plan/PDrawCommand.java), [`PDrawGroup`](../common/src/main/java/com/arcanc/pulselib/content/renderer/plan/PDrawGroup.java), and [`PRenderPlan`](../common/src/main/java/com/arcanc/pulselib/content/renderer/plan/PRenderPlan.java) are backend plan data; normal mods should submit through `PRenderQueue` rather than construct them.
* [`PGpuDeformerBuffers`](../common/src/main/java/com/arcanc/pulselib/content/model/deformer/gpu/PGpuDeformerBuffers.java) streams supported deformer stacks to the renderer. Its lifecycle is managed by PulseLib.
* [`PModelResource`](../common/src/main/java/com/arcanc/pulselib/content/model/resource/PModelResource.java), [`PTextureReference`](../common/src/main/java/com/arcanc/pulselib/content/model/PTextureReference.java), [`PResourceCache`](../common/src/main/java/com/arcanc/pulselib/util/PResourceCache.java), and [`RuntimeLoader`](../common/src/main/java/com/arcanc/pulselib/content/model/textures/atlas/RuntimeLoader.java) manage registered model resources, model-local texture resolution, and the runtime texture atlas.
* Attachments are centered on [`PLivingAttachmentDefinition`](../common/src/main/java/com/arcanc/pulselib/util/attachments/PLivingAttachmentDefinition.java), [`PLivingAttachments`](../common/src/main/java/com/arcanc/pulselib/util/attachments/PLivingAttachments.java), [`PAttachmentBinding`](../common/src/main/java/com/arcanc/pulselib/util/attachments/PAttachmentBinding.java), and [`PAttachmentAnchor`](../common/src/main/java/com/arcanc/pulselib/util/attachments/PAttachmentAnchor.java).

## Player animations

* [`PPlayerAnimationDefinition`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDefinition.java) configures bindings, masks, blend modes, weights, activation crossfades, cycle synchronization, controllers, Molang queries, animation-owned mesh deformers through `Builder.deform(...)`, and first-person held-item behavior through `Builder.itemRenderPolicy(...)` and `Builder.itemVisibility(...)`.
* [`PPlayerAnimations`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimations.java), [`PPlayerAnimationHandle`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationHandle.java), and [`PPlayerAnimationInstance`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationInstance.java) expose runtime registration and per-player state.
* [`PPlayerPart`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerPart.java), [`PPlayerAnimationMask`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationMask.java), [`PPlayerAnimationBlendMode`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationBlendMode.java), and [`PPlayerAnimationWeight`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationWeight.java) define how a player pose is applied.
* [`PPlayerAnimationFrame`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationFrame.java), obtained with `PPlayerAnimationInstance.sampleFrame(partialTick)`, exposes full model-space sockets through `actionTransform`, bind-root-relative transforms through `rootRelativeTransform`, and current-root-relative transforms for an already rooted stack through `currentRootRelativeTransform` / `currentRootRelativeMatrix`. `modelMatrix` / `bindMatrix` preserve exact parent products, including shear that TRS snapshots cannot represent. `cameraAnchorModelDelta` supplies camera-origin displacement and inherited orientation in the native visual reference frame. See [Transform spaces](player-animations.md#transform-spaces) and [Animated camera](player-animations.md#animated-camera).
* [`PPlayerAnimationAnchor`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationAnchor.java) and [`PPlayerAnimationAnchors`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationAnchors.java) name semantic sockets such as `RIGHT_ITEM`, `LEFT_ITEM`, and `FIRST_PERSON_CAMERA`. [`PPlayerAnimatedAttachmentRenderer`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/attachment/PPlayerAnimatedAttachmentRenderer.java) receives an already positioned stack through [`PPlayerAnimatedAttachmentContext`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/attachment/PPlayerAnimatedAttachmentContext.java). Render local geometry; applying the socket transform to that stack again duplicates it.
* [`PPlayerFirstPersonSettings`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PPlayerFirstPersonSettings.java) enables first-person output and selects [`PFirstPersonCameraMode`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PFirstPersonCameraMode.java). [`PFirstPersonPresentation`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/firstPerson/PFirstPersonPresentation.java) supplies the shared camera-relative VIEW frame for arms, items, anchors, and meshes. `ANIMATED` follows the full camera-anchor hierarchy; `VANILLA` keeps the actual camera position/rotation while retaining that authored presentation frame.
* [`PPlayerAnimationDeformer`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformer.java), [`PPlayerAnimationDeformerValueSource`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformerValueSource.java), and [`PPlayerAnimationDeformerContext`](../common/src/main/java/com/arcanc/pulselib/content/player/animation/PPlayerAnimationDeformerContext.java) attach a deformer stack to a definition and sample channels from its player/controller context.

## Graph sampling and pose metadata

Runtime overlay methods on `PAnimationGraphRuntime`: `overlaySpeed`, `setOverlaySpeed`, `restartOverlay`, `stopOverlay`, each with state-name and state-index overloads. Graph sampling exposes `sampleBasePose`, `samplePose`, an interpolated `layers` overload, and a `tickPrecise` overload accepting a base snapshot sampler. See [overlay control](animatables-and-controllers.md#runtime-overlay-control) and [RESTART snapshots](animatables-and-controllers.md#restart-pose-snapshots) for timing, errors and custom consumers.

`PPose.copy()` deeply copies TRS, channel masks, scalar values, visibility and dirty/valid flags. `hasTranslation`, `hasRotation`, `hasScale`, `hasScalarChannel`, `hasVisibility`, `isVisible`, `visibility` and `scalarChannelCount` expose the corresponding metadata. `PPoseMixer.blend` blends resolved poses; `PPoseMixer.Transition(mixer, referencePose, initialLayer)` supplies the actual reference/hierarchy for RESTART while preserving the existing constructor.

Nonidentity values written through the original mutable TRS getters still contribute to mixing. Use the `PPoseWriter` setters (or `set` / `setAnimated`) when declaring explicitly animated identity channels, so their presence can be distinguished from an absent channel.

`PAnimationController.setGraphSnapshotContexts(provider)` supplies fresh game-specific queries for tick-boundary capture. `PAnimationRuntime.captureGraphBase` also accepts a context provider for custom controller integrations. Persistent variable storage stays local to each controller.

Overlay definition/runtime speeds are signed. Activation/restart uses the clip end for negative speed and the beginning for positive speed; zero pauses and retains the last direction. A speed change preserves the cursor; `NaN`/Infinity are rejected. Reverse completion, fade-out and event dispatch follow the zero endpoint. See [runtime overlay control](animatables-and-controllers.md#runtime-overlay-control).
